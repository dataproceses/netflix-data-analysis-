# 🎬 Netflix Data Analysis

## 📊 Overview

This project explores and analyzes Netflix's content library, focusing on trends by content type, release year, country, and genre. The goal is to uncover key insights about Netflix's global content strategy using data-driven techniques and visualizations.

---

## 🎯 Objectives

- Determine the most common content types (Movies vs TV Shows)
- Analyze the growth of Netflix content over time
- Identify top genres and content-producing countries
- Explore rating distributions and average durations
- Visualize trends and provide actionable insights

---

## 🧩 Dataset Features

| Column         | Description                                       |
|----------------|---------------------------------------------------|
| `show_id`      | Unique identifier for each show                   |
| `type`         | Movie or TV Show                                  |
| `title`        | Name of the show or movie                         |
| `director`     | Director name(s)                                  |
| `cast`         | Main actors                                       |
| `country`      | Country of production                             |
| `date_added`   | Date added to Netflix                             |
| `release_year` | Year the content was released                     |
| `rating`       | Content rating (e.g., PG, TV-MA, etc.)            |
| `duration`     | Movie duration or number of seasons               |
| `listed_in`    | Genres/categories                                 |
| `description`  | Short summary                                     |
| `year`, `month`, `day` | Extracted from `date_added`               |

---

## 🛠️ Tools & Libraries

- Python 3.x
- Pandas & NumPy for data manipulation
- Matplotlib & Seaborn for visualizations
- Jupyter Notebook for analysis

---

## 📈 Key Analyses

- ✅ Content type distribution
- ✅ Year-wise and month-wise additions
- ✅ Top genres and content-producing countries
- ✅ Rating frequency and average durations
- ✅ Most common directors and cast members
- ✅ Genre popularity over time
